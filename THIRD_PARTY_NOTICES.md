# Third-party notices

AuraLead AI ships or adapts the open-source work listed below (plan §10, design spec "Aurora").
Every version is pinned exactly in `package.json`; the full license text of each npm package is
in its folder under `node_modules/` and travels with the installed package.

## 1. Code adapted into this repository

These files contain code or techniques taken from MIT-licensed projects. Each file names its
source in its header comment. The MIT license text is reproduced in section 5.

| Project | License | Copyright | Where it is used |
|---|---|---|---|
| [shadcn/ui](https://github.com/shadcn-ui/ui) (new-york registry) | MIT | Copyright (c) 2023 shadcn | `src/components/ui/**`: primitives generated by the shadcn CLI, then restyled |
| [Magic UI](https://github.com/magicuidesign/magicui) | MIT | Copyright (c) Magic UI | Techniques re-implemented in `src/components/visual/`: `BorderBeam.tsx` (offset-path rect light with a border-band mask), `AnimatedBeam.tsx` (quadratic curve between two element centers, recomputed on resize), `Marquee.tsx` (two translating tracks), `OrbitRing.tsx` (rotate / translate / counter-rotate orbit), `Meteors.tsx` (rotated head and tail streaks), `SpotlightCard.tsx` (pointer-positioned radial wash and border, after `magic-card`) |
| [Motion Primitives](https://github.com/ibelick/motion-primitives) | MIT | Copyright (c) 2024 ibelick | `src/components/visual/TiltCard.tsx`: pointer-normalized tilt angles (after `tilt`), re-implemented with CSS variables instead of springs |

public domain.

## 2. Inspired by, not copied

The following libraries were studied for look and feel only. No source code from them is in this
repository, and none may be added: their terms forbid redistributing or porting their components.

| Project | Terms | What it inspired |
|---|---|---|
| [Aceternity UI](https://ui.aceternity.com) | Custom licence (no redistribution of source) | The idea of an aurora background and a moving border. `AuroraBackdrop` is an original CSS build (transform-only drifting radial blobs plus grain), and `ChromaBorder` uses the standard CSS `@property` conic-angle technique |
| [Skiper UI](https://skiper-ui.com) | Free tier: use with attribution; not an open-source license | General direction for cinematic hero and card treatments; no component was used |
| [React Bits](https://github.com/DavidHDev/react-bits) | MIT + Commons Clause v1.0 (no porting or redistribution) | Aurora, spotlight card and gradient text as visual references; all implementations here are original |
